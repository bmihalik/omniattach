# Changelog

## 0.1.0

- Opt-in external-tool adapters: Poppler, Tesseract, LibreOffice, FFmpeg audio/frames, FFprobe and whisper.cpp.
- Explicit custom-command output contracts for Markdown, transcript JSON and declared files.
- Injectable runner, Unix bounded dual-stream process supervision, cancellation and process-group cleanup.
- Owned artifact bundle, checked output paths, source hashes, diagnostics and JSON manifests.
- Explicit backend registry, examples, architectural diagrams and command/native-tool verification tests.

Initial release: no promise of full RagDBMan parity, OCR/ASR quality, OS sandboxing or live-feed handling.
