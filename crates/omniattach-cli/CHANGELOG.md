# Changelog

## 0.1.0

- CLI binary omniattach with capabilities/probe/xml-probe/plan/convert subcommands.
- Production facade adapter with explicit external registration/permission, source options and policy forwarding.
- Durable conversion export before success JSON, stderr NDJSON progress and symbolic errors/exit codes.
- Namespace-aware bounded XML structural inspection, encoding/DTD/entity constraints.
- Shared cancellation signals, embedding interface, Python subprocess example and Mermaid architecture.
- Independent no-sibling inspection/transport harness: 50 integration tests plus one rustdoc example.

Compatibility caveat: actual sibling facade source was unavailable for integration compilation. Actual-workspace integration tests are supplied, not reported as executed.
