# Changelog

## 0.1.0

- Standalone document extraction crate with optional Office and PDF families.
- Structured document/block/table/cell model and explicit provenance.
- Namespace-aware XML table mappings with missing/empty and repetition policy.
- Native ODS values/formulas and bounded repetition; cached formula access in Calamine workbooks.
- Markdown/text/JSON and configurable CSV renderers.
- Example conversion program, XML example/mapping, minimal package fixtures and feature-matrix CI.

Initial implementation; not a claim of full RagDBMan parity or production hardening.
