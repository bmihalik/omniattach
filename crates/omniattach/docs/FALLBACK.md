# Opt-in facade fallback (core stage)

Ordinary plan/convert and registration ambiguity behavior are unchanged. Use engine.convert_with_fallback(&request, &context, &FallbackPolicy::new(["documents", "marker", "mineru"])) to request ordered attempts. request.route must be absent. All candidate IDs must be unique/nonempty; 1..=32 are allowed. The full chain is preflighted for route existence, format/goal compatibility and permissions before any converter executes. A denied external candidate invalidates the chain even if an earlier native candidate might succeed. No tools are health-probed during preflight.

Each candidate optionally replaces request options, rather than merging them; use FallbackCandidate::new("marker").with_options(json!({})) when native settings must not reach an external adapter. The initial request is snapshotted once with bounded input copying and hashing. Existing convert then creates isolated attempt workspaces and independent input copies. Only the selected bundle is retained; rejected bundles are explicitly closed. Failed converter workspaces retain existing best-effort drop cleanup.

Default retry classes are a backend Spawn with NotFound and ProcessFailed with an explicit exit code. Permission-denied spawn, signal-only process failure, invalid input/output/configuration, cancellation, typed limits, unknown/opaque converter errors and nested fallback errors are terminal. No message/stderr matching is used; an ordinary process exit can still conceal an upstream cause that the tool did not type. Backend/per-attempt timeouts require explicitly adding AttemptTimeout to retry_on. An exhausted overall deadline is always terminal.

Acceptance defaults to AnySuccess, including legitimate artifact-only output. NonEmptyText and MinTextChars count non-whitespace Unicode scalar characters across text fragments, not tokenizer tokens and not proof of table/figure/equation recovery. Results undergo normal engine artifact validation before acceptance; unsafe artifacts are terminal, not a reason to try another backend.

The context timeout covers snapshot, preflight, all attempts and orchestration. Optional per_attempt_timeout_ms caps each attempt without extending the overall deadline. Zero is invalid. Timeouts are cooperative for in-process work. Input/export bounds apply to the snapshot/each attempt and selected bundle, not a cumulative live disk/RAM/CPU sandbox; maximum attempts is also bounded. Repeated work can cost up to the sum of attempt budgets.

Success adds an omniattach/fallback/0.1 payload and FALLBACK_SELECTED warning. The manifest route is the actual winner; top-level source identity is the original input and elapsed time is whole-chain time. Existing Markdown paths, layout-package payloads and artifact bytes are not rewritten. Converter payload source names can refer to snapshot copies, explicitly diagnosed. Failure is Error::Fallback { report, source }, retaining a typed terminal source or FallbackExhausted. Attempt details are limited to 1024 characters but may contain sensitive paths/stderr. Options are not logged.

Intermediate converter Completed/Failed progress events are suppressed; staging/converting events use chain-relative elapsed time. A single final completion/failure is emitted. Attempt-level progress messages beyond this are not added.

This is the core stage. Native document error mapping and full orchestration/layout regression tests follow in the next commit. The Document error variant is available now, but the existing native adapter still flattens errors until that follow-up; opaque Converter errors remain terminal. No CLI flags, automatic chain, backend installation, main-branch merge or publication is included. Rust compilation/tests have not been run in the preparation environment.
